# Aula 09: Tipos de dados abstratos, encapsulamento e orientação a objetos (exemplos)

Referência: Sebesta, *Conceitos de Linguagens de Programação*, 11ª ed., Caps. 11 e 12.

## Como executar no navegador

Abra o OneCompiler da linguagem, **apague o código de exemplo, cole o arquivo inteiro** e clique em **Run**.

| Linguagem | Endereço |
|---|---|
| Java | https://onecompiler.com/java (a classe principal se chama `Main`; outras classes ficam no mesmo arquivo) |
| C++ | https://onecompiler.com/cpp |
| C# | https://onecompiler.com/csharp |
| C | https://onecompiler.com/c |
| Python | https://onecompiler.com/python |
| Go | https://onecompiler.com/go |
| Rust | https://onecompiler.com/rust |
| JavaScript | https://onecompiler.com/nodejs |
| Ruby | https://onecompiler.com/ruby |

**Todos os 33 programas foram executados no OneCompiler em 23/09/2026** e produziram a saída indicada nos comentários. A exceção é `pilha_c.c`, que imprime um valor "lixo" diferente a cada execução, de propósito.
